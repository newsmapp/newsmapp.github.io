# NewsMap — contributor guide

Global news directory: static-first Astro site on Cloudflare Workers. `SPEC.md` is the source of truth; decisions live in `docs/adr/`.

## Commands

| Task                        | Command                                                              |
| --------------------------- | -------------------------------------------------------------------- |
| Everything a PR must pass   | `pnpm check`                                                         |
| Dev server                  | `pnpm dev`                                                           |
| Unit tests / coverage       | `pnpm test` / `pnpm test:coverage`                                   |
| E2E + accessibility         | `pnpm e2e` / `pnpm a11y`                                             |
| Build (site + search index) | `pnpm build`                                                         |
| Catalog tooling             | `pnpm catalog:<validate\|health\|draft\|import\|add\|icons\|report>` |
| Local D1                    | `pnpm db:migrate:local`                                              |

`mise run check` is equivalent to `pnpm check`.

## Layout

- `data/` — the catalog (Git is the CMS). JSON validated by Zod schemas in `src/schemas/`.
- `src/lib/` — pure, runtime-agnostic logic (no Astro, no Cloudflare APIs). Most tests live here.
- `src/server/` — Worker-side code: D1, webhooks, cron, rate limits.
- `src/pages/` — routes. Static by default; only `/go/*`, `/api/*`, `/badge/*`, `/admin/*` render on demand.
- `src/components/`, `src/layouts/`, `src/styles/` — UI.
- `tools/` — CLIs run with `tsx` (catalog, audits, snapshot). Never imported by `src/`.
- `drizzle/migrations/` — D1 migrations, generated by `pnpm db:generate`.

Boundaries are enforced by dependency-cruiser (`.dependency-cruiser.cjs`).

## Rules

- Never commit secrets. Local secrets go in `.dev.vars` (see `.env.example`); production uses `wrangler secret put`.
- Only the owner marks an outlet `verified` or a country `published`. Tools may draft `candidate` outlets only.
- Organic outbound links are direct `href`s with a click beacon; sponsored and affiliate links go through `/go/<id>/` (ADR 0006). No third-party scripts, fonts or images at runtime, except the Turnstile widget on forms.
- No raw IP or User-Agent is stored. Clicks are aggregated with a daily-salted hash.
- Run `pnpm check` before committing. Conventional Commits, one logical change per commit.
- Commits and PRs carry no tool attribution: no `Co-Authored-By` trailers, no "generated with" lines, no e-mails or local paths. Never use `git add -A` blindly; stage explicit paths.
- Node 24 (`nvm use 24`): dependency-cruiser rejects Node 25.
- After changing `wrangler.jsonc`, `pnpm typecheck` regenerates binding types.
